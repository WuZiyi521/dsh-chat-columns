## 三个必须先说的结论

1. **0.1.4 的主会话判据是错的，0.1.5 已修**（`[data-slot="main"]`；实测右栏子智能体聊天会抢走主会话）。
   0.2 全部设计建立在修正后的判据上。
2. **「插件只能读 DOM」不成立**：`ctx.get("sessions")` 可读 `hasMore/loadingOlder` 与节点模型。
   但那是内部服务，**不是契约**——0.2 的规则是「DOM 必须能独立跑完，服务只是加速，降级必须可见」。
3. **无缝模式与宿主锚点契约天然冲突**（宿主锚点假设 `dy/ds = −1`，窗口化布局不满足）。
   这不是实现细节，是 P1 必须先证明的可行性问题；证明不过就不做 B。
