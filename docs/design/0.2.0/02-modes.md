# 02 · 三种模式的行为定义

> 本文只定义「用户看到什么、什么算对、什么算错」，不定义实现（实现见 03–06）。
> 每个模式给三样东西：**语义**、**可观测的验收点**、**明确的非目标**。
> 标记：`[已证实]` / `[假设]` / `[风险]`。

---

## 共同前提

- 三种模式**互斥**：任一时刻只有一个模式生效，切换时旧模式的 DOM 痕迹必须清零。
- 三种模式**都只处理活动线程**（当前主会话）；不排版后台会话。
- 三种模式**都必须**在 `hero`（无会话）、`none`（无内容）、`ambiguous`（分不清主面板）三种状态下
  安全退化：不报错、不留残余、不猜。
- **只读不越权**：插件不写宿主 `scrollTop`（无缝若将来需要，走 §B.5 的单独立项）。

---

## A · 报纸（Newspaper）

### A.1 语义

把**同一份**实时会话压进宿主唯一的滚动容器，横向切成 N 列，列高 = 内容总高 ÷ N，
三列并排、同步滚动。它回答的问题是「这段对话的整体形状是什么」。

- 一份 React 节点树，**不复制、不搬动**。
- 列是 CSS 分栏（`column-count`），不是盒子：列不可单独滚动，也不承载状态。
- 锚点、滚动、`加载更早` 全部由宿主负责；插件只在排版上动手。

### A.2 列数与列宽

- `[已证实]` 现行规则：`cols = clamp(1, 3, floor((W + gap) / (minW + gap)))`，`minW = 420`，`gap = 24`；
  窄到 `minW` 以下时压到 260px 硬下限，仍要保证文档不横向溢出。
- 列数由**容器宽度**决定，不跟窗口宽度；侧栏开合会改变列数。
- 用户手动选 1/2/3 时优先于自动；选择持久化。

### A.3 分页与边界

- **矮卡片不被切断**：高度 ≤ `min(420, 45% 列高)` 的行整体保留（`break-inside: avoid`）。
  更高的行允许跨列——这是报纸读法的代价，写进 README，不假装没有。
- 默认**不自动加载更早**；保留宿主的手动按钮，并额外提供「一键加载全部」（见 06）。
- 加宽靠把 `--dsh-chat-content-width` 设成 `calc(100% - 32px)`，卸载时原样还回。

### A.4 验收观察点（可测）

| # | 观察 | 通过标准 |
|---|---|---|
| A-1 | 三列等高 | 三列高度差 ≤ 1%（列宽），且列底不出现 > 1 行高的空白 |
| A-2 | 不切断 | 高度 ≤ 420px 的行，`getBoundingClientRect()` 不跨列边界 |
| A-3 | 滚动同步 | 滚动 500 次，`scrollHeight/scrollTop` 由宿主维护，插件写入次数 = 0 |
| A-4 | 卸载 | 类名、`columnCount`、atomic 标记、宽度变量、`data-dshc*` 全清 |
| A-5 | 退化 | hero/none/ambiguous 下无列、无残留、徽标不撒谎 |

### A.5 非目标

- 不做列独立滚动、不做元素级美化、不做「读到哪里」的记忆（宿主已有）。

## B · 无缝（Seamless）

### B.1 语义

把**一份连续内容**按可见列高 `H` 切成首尾相接的窗口：第 `c` 列显示流区间
`[s + c·H, s + (c+1)·H)`，`s` 是阅读位置。屏幕上的接缝（列 `c` 的底边 = 列 `c+1` 的顶边）
**钉在 `y = H`**；滚动时是**内容连续穿过接缝**，不是整页翻过去。

一句话判据：**滚动 1px，内容在屏幕上移 1px，且跨列处不多不少。**

### B.2 必须成立的四条

1. **连续**：滚动过程中任意时刻，屏幕上任意一行的位置 = 它的流坐标 − `s`，
   误差 ≤ 1px（跨接缝的那一帧除外）。
2. **守恒**：任一 `s` 下，`[s, s + N·H)` 内的每一段流内容**恰好出现一次**；无空洞、无重复。
3. **不切断优先于不跳**：允许长代码块/大图把一列顶出留白，**不允许**把内容腰斩后两边各半。
4. **无位置突跳**：除「跨接缝」外，任意相邻两帧同一行的位移差 ≤ 1px。

### B.3 与宿主的关系

- `[已证实]` 宿主锚点契约是 `dy/ds = −1`；任何窗口化布局都不满足它，表现为
  **恢复位置只剩相位**、**加载更早差 `k·H`**（04 §3.1/§3.3）。
- 0.2 的硬约束：**不写宿主 `scrollTop`**。若 P1 证明必须写，单独立项、单独分支、
  在 CHANGELOG 显式声明（04 §4）。
- `H` 的口径必须减掉 composer 的遮挡段（`[已证实]` composer 是 sticky 在 scrollport 底部），
  否则接缝藏在输入框下面。

### B.4 加载

- 默认**自动加载更早**。
- `[已证实]` 「触顶自动加载」与「零跳动」结构性冲突：批次在途时任何 wheel/touch/key
  都会让宿主 `stopPreserving()`，commit 时不补偿、整屏被推下去。
  → B 必须在下列三条里**明确选一条**，并写进 CHANGELOG：
  (a) 等手势静默（`scrollend` + 停留）后再加载；
  (b) 加载后由插件补位（= 写一次 `scrollTop`，属例外，需声明）；
  (c) 接受整屏位移，但在 UI 上给出可预期的提示。
  **不许「看情况」。**

### B.5 门禁（P1 未过不许进 P4）

`[假设]` 见 04 §5 的 T1–T11。最低门槛：内容守恒误差 ≤ 2px、接缝 p95 ≤ 0.1H、
非加载段插件 `scrollTop` 写入次数 = 0、帧 p95 ≤ 33ms。任一条不过 → 退 R1 或降级为「A+C」。

### B.6 验收观察点

| # | 观察 | 通过标准 |
|---|---|---|
| B-1 | 接缝位置 | 列底到 `y=H` 的中位差 ≤ 0.1H，p95 ≤ 0.5H |
| B-2 | 连续性 | 40 帧连续滚动，参照行 `|Δy + Δs| ≤ 0.5` |
| B-3 | 守恒 | 20 个采样点，行到流坐标映射无空洞/无重复，误差 ≤ 2px |
| B-4 | 不写滚动 | 非加载段 `scrollTop` 写入 = 0 |
| B-5 | 加载后定位 | 一次加载后，参照行位移 ≤ 2px（或按 B.4 声明的例外） |

### B.7 非目标

- 不做「翻页」、「缩放适配」、「行级虚拟化」（R3 才涉及，且未采纳）。

## C · 复制（Duplicate）

### C.1 语义

每个阅读栏显示**同一会话的完整内容**，各栏有**独立的垂直滚动位置**——
可以把第 1 栏停在第 20 轮、第 2 栏停在第 120 轮，左右对照。它解决的是「前后翻查」，
不是「一屏看全」（那是 A），也不是「顺着读」（那是 B）。

### C.2 硬约束（已经过 0.1.x 论证）

- **不搬动宿主 React 节点**：搬走会破坏 keyed seat，下次渲染重复/错乱。
- **不克隆带交互状态的 React DOM 当可交互副本**：克隆出来的是死 DOM，按钮点了没用。
- 因此只能是**只读渲染副本**，并且**必须让用户看得出来**。

### C.3 内容与保真

- 内容来源优先用宿主节点模型（`complete = "full"`），拿不到时降级为 DOM 快照
  （`complete = "partial"`，UI 标「降级快照·可能缺内容」）。
- `[已证实]` DOM 快照会缺内容：折叠 JSON 不渲染 payload、展开截断 2 万字符、`hidden` 行被摘掉。
  所以**不允许**把快照当成「完整」展示。
- 白名单渲染：未知的行类型渲染为显式占位，**不许静默丢弃**。

### C.4 只读的边界

| 元素 | 处理 |
|---|---|
| 审批卡 | 不在消息流里（在宿主 composer 槽）→ 副本不渲染；宿主 composer 保持可用 |
| 按钮/表单/输入 | 永不渲染 |
| 代码块「复制」 | 保留为副本自带的按钮（副本自己的能力，不依赖宿主） |
| 外链 | 保留可点，新窗口打开；内链降级为纯文本 |
| 一切交互控件 | 不做「禁用态」，直接不渲染——灰按钮仍会被点 |

防误点：栏头常驻「只读」标签 + 首次进入的一次性横幅。

### C.5 滚动与同步

- 每栏独立 `overflow-y: auto`；栏内锚点自算（`overflow-anchor: none` + 记录参照行）。
- **共用一个历史源**：任一栏触顶只发一个 `requestOlder()`，由 HistoryController 单飞；
  加载完成后**所有栏同一版本一起更新**，不允许各自请求。
- 新消息/流式更新：按 `ContentModel.version` 增量提交；每栏在提交前后各测一次锚点，
  超出阈值就先补偿再继续。

### C.6 验收观察点

| # | 观察 | 通过标准 |
|---|---|---|
| C-1 | 完整性 | 三栏内容行数一致且 = 源行数；与源逐行指纹比对一致率 ≥ 99.5% |
| C-2 | 只读 | 栏内可聚焦元素 = 0（代码复制按钮除外，且带 `data-copy` 标记） |
| C-3 | 独立滚动 | 三栏 `scrollTop` 互不影响；任一栏滚动不改变其他栏 |
| C-4 | 共享加载 | 一次触顶只产生 1 次 `requestOlder()`；加载后三栏行数同步 |
| C-5 | 性能 | 247 行 × 3 栏首帧 ≤ 300ms；总节点数 ≤ 3× 源节点 |
| C-6 | 降级 | 无服务时显示「降级快照」标记，且不声称完整 |

### C.7 非目标

- 不做栏内交互、不做栏间联动滚动（0.2 不做；将来若做，属于新需求）。

## 模式切换规则（三模式共用）

1. 切换 = `unmount` 旧策略 → `mount` 新策略；旧策略的容器、监听、样式必须全部释放。
2. `ContentModel` 不随模式重建（同一 version），避免切换时重复加载。
3. 历史加载在切换时**取消在途批次**，状态回 `idle`；已加载的内容保留（属于源，不属于模式）。
4. 用户偏好按模式分别记忆；「自动加载」默认值只在用户从未显式设置时生效。
5. 切换失败（策略 mount 抛错）→ 回退到报纸模式，并在徽标上显示错误，不留在半装状态。
